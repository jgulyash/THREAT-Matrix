# Design material

Maintainer design notes for the reference viewer. This folder sits outside `docs/` on purpose: `docs/` is published by GitHub Pages, and this material is not part of the published site.

| File | What it is |
|---|---|
| `palette-comparison.html` | The color palette study behind the viewer's visual identity. Open it locally in a browser. It loads a web font from Google Fonts when opened. |

Nothing in the viewer, the data, or the gates depends on these files.
